# Core Release Non-Goals

The following features are deliberately excluded from the first release:

- RESP3
- TLS and ACL
- Lua scripting
- Transactions
- Pub/Sub
- Replication, Sentinel, and Redis Cluster
- Redis RDB format compatibility
- Concurrent command execution on multiple threads
- Full Redis command and option compatibility

Raft is a separate extension after the single-node Definition of Done is satisfied.
